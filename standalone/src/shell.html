Print guide

  • Print flat, label side up, 0.2 mm layers or finer, 3+ walls.
  • Enable Arachne / variable line width so pin tips are not dropped.
  • Clean stringing and seams off the pins before the first play.
  • Grooves are 1.2 mm deep; pins are triangle ramps on the groove walls.
  • Records, settings and albums are saved in this browser — use BACKUP to keep a copy.
