Fisher-Price Record Maker — offline build guide
================================================

ONE-CLICK START
  Windows : double-click  start-windows.bat
  macOS   : double-click  start-mac.command   (first time: right-click → Open, then "Open" to allow it)
  Linux   : ./start-linux.sh

  The script checks for Python and Node.js, creates the two .env files,
  installs the packages (first run: a few minutes), starts the backend on port 8001
  and the web app on port 3000, then opens http://localhost:3000 in your browser.

WHAT YOU NEED INSTALLED ONCE
  Python 3.10 or newer ....... https://www.python.org/downloads/   (Windows: tick "Add python.exe to PATH")
  Node.js LTS ................ https://nodejs.org/
  MongoDB .................... OPTIONAL. Without it, every record / album / setting is saved as a JSON file
                               in the  data/records  folder next to the start script (back it up by copying
                               the folder). If MongoDB is installed and running, the script uses it instead.

STOPPING
  Windows: close the two black windows ("FP Backend", "FP Frontend").
  macOS/Linux: press Ctrl+C in the terminal that opened.

PROBLEMS
  "python is not recognized"  → reinstall Python with "Add to PATH" ticked, or open a new terminal.
  Port 3000 / 8001 in use     → close the other app or edit the ports in the start script AND frontend/.env.
  Blank page / "network error"→ the backend is not running; check the FP Backend window / data-backend.log.
  No sound in the preview     → press the TEST button next to the play controls; the browser must allow
                                audio on the page (click anywhere once) and the tab must not be muted.
  Cannot save records         → check the data/records folder is writable (file mode), or that MongoDB is
                                running if backend/.env has MONGO_URL.

MANUAL START (if you prefer typing)
  backend : cd backend && python -m venv .venv && (.venv\Scripts\activate | source .venv/bin/activate)
            pip install -r requirements-local.txt
            echo FP_STORAGE=files > .env && echo DATA_DIR=../data/records >> .env
            (or MONGO_URL=mongodb://localhost:27017 + DB_NAME=fisher_price to use MongoDB)
            uvicorn server:app --host 0.0.0.0 --port 8001
  frontend: cd frontend && npm install --legacy-peer-deps
            echo REACT_APP_BACKEND_URL=http://localhost:8001 > .env
            npm start            (or  npm run build  for a static HTML5/CSS3/JS bundle in frontend/build)
